# Migration audit

The verified 2026-08-24 chain contains 86 migrations targeting SQLite. Forward migrations secure staff and guest invitation credentials, enforce tenant consistency, complete localization and menu media, preserve item-cancellation history, migrate monetary storage to integer cents and add menu-item variants without rewriting historical deployed migrations. The schema retains foreign keys/indexes, soft-deleted history and immutable order snapshots; no view, trigger or stored routine dependency was introduced.

Historical migrations include model-based backfills and therefore present drift risk, but deployed migration files were not rewritten. The current chain contains 88 forward migrations. The additive allergen-snapshot migration was exercised against existing order/ticket rows in an isolated SQLite file: rollback preserved both rows, reapply restored both JSON columns and legacy rows received safe empty-list defaults. Earlier isolated `migrate:fresh --seed`, repeat-seed and guest-invite contraction rollback/reapply evidence remains valid; the contraction preflight still refuses to remove a populated plaintext credential. The application database was never refreshed or truncated. The canonical schema contract is [`data-model.md`](data-model.md).
