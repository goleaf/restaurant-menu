# Schema snapshot

The canonical relational model and value conventions are in [`data-model.md`](data-model.md). The current schema is generated by the migration chain and must be inspected from the target connection before schema work; this document does not duplicate an easily stale column dump.

Baseline on 2026-08-22: SQLite; 48 application/framework tables; 65 migrations; no views, triggers or routines; 41 first-party Eloquent models and 41 factories.
