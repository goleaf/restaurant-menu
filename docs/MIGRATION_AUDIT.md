# Migration audit

The verified 2026-08-24 chain contains 86 migrations targeting SQLite. Forward migrations secure staff and guest invitation credentials, enforce tenant consistency, complete localization and menu media, preserve item-cancellation history, migrate monetary storage to integer cents and add menu-item variants without rewriting historical deployed migrations. The schema retains foreign keys/indexes, soft-deleted history and immutable order snapshots; no view, trigger or stored routine dependency was introduced.

Historical migrations include model-based backfills and therefore present drift risk, but deployed migration files were not rewritten. Isolated `migrate:fresh --seed` completed all 86 files, a second default seed was idempotent, and the final guest-invite contraction completed rollback and reapply. Its preflight refuses to drop `table_sessions.guest_invite_token` while any plaintext value remains; the existing local database was checked read-only, contained zero such values and was upgraded without refreshing or deleting rows. The canonical schema contract is [`data-model.md`](data-model.md).
