# Schema snapshot

The canonical relational model and value conventions are in [`data-model.md`](data-model.md). The current schema is generated by the migration chain and must be inspected from the target connection before schema work; this document does not duplicate an easily stale column dump.

Current evidence on 2026-08-24: SQLite; 86 migrations; no views, triggers or routines; 48 first-party Eloquent models and 48 factories. Inspect the active connection before schema work because migration status/schema metadata remain executable truth. Requirement-to-table evidence is kept in [`REQUIREMENTS_TRACEABILITY.md`](REQUIREMENTS_TRACEABILITY.md).
