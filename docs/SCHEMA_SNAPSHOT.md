# Schema snapshot

The canonical relational model and value conventions are in [`data-model.md`](data-model.md). The current schema is generated by the migration chain and must be inspected from the target connection before schema work; this document does not duplicate an easily stale column dump.

Current inventory on 2026-09-14: SQLite; 88 migrations; no views, triggers or routines; 49 first-party Eloquent models and 49 factories, including the cache-entry mapping without a new table. All 88 migrations completed an isolated empty-database down/up roundtrip; see [`MIGRATION_AUDIT.md`](MIGRATION_AUDIT.md) for populated-data rollback restrictions. Inspect the active connection before schema work because migration status/schema metadata remain executable truth. Requirement-to-table evidence is kept in [`REQUIREMENTS_TRACEABILITY.md`](REQUIREMENTS_TRACEABILITY.md).
