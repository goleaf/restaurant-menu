# Settings contracts

Existing settings URL enters the same class-based component. URL section allowlist: profile,guests,settlement,locale,advanced; language en/lt/ru; optional group target allowlisted. Search is local/bounded and never persists a setting.

Each Form exposes only owned input, independent baseline/error/success; group save takes expected fingerprint and request UUID. Save/cancel affect only selected group. Profiles and media are separate visible operations. Legacy broad save is removed. Action uses exact allowlist, fresh scoped actor/branch policy, transaction, expected-version check, write veto handling, truthful audit and receipt.

Preview uses a pure profile presenter, explicit saved/draft label, chosen language/width and safe URLs. No real GuestEntry mount or guest token/session mutation.

Cleanup preview is locked server data with explicit100 candidates, settings fingerprint, timestamps/status/activity proof and has_more. Confirm is a separate explicit request; updated candidates skipped, configuration conflict requires preview again, duplicate receipt returns the same bounded report.
